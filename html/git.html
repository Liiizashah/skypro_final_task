Git

  • git init - создает новый локальный репозиторий в текущей папке.
  • git add - добавляет файл в область изменений.
  • git status - показывает текущее состояние репозитория, то есть изменение или добавление файлов.
  • git commit - сохраняет в репозитории изменения с комментарием .
  • git push - отправляет локальные коммиты к удаленному репозиторию.
  • git pull - загружает изменения из удаленного репозитория и объединяет их с локальными изменениями./
